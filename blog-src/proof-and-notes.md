一份数学笔记的价值，不只在于结论是否整齐，还在于过一段时间之后，能不能沿着记录重新走完那条推理。

## 01 / 先写条件，再写结论 {#conditions}

看到 (x² − 1) / (x − 1)，很容易想到因式分解，再约去相同的因子：

```
(x² − 1) / (x − 1)
= (x − 1)(x + 1) / (x − 1)
= x + 1，条件：x ≠ 1
```

最后这个条件不能丢。原式在 x = 1 时没有定义，而 x + 1 在这里有定义。因此，两者在原式的定义域内相等，却不能直接把原式当作一个在所有实数上都有定义的表达式。

写笔记时，把“对象是什么”“在哪个范围内讨论”“需要哪些前提”放在同一个位置。条件不是附注，而是结论的一部分。

## 02 / 留下每一步的理由 {#steps}

公式变形的下一行，应该能回答“用了什么”。在上面的例子中，第一步用了平方差公式，第二步用了非零因子的约分。写下这些理由，能把看似顺手的操作拆成真正可以检查的推理。

不需要给每个加减乘除写长段说明，但应保留容易发生跳步的地方。例如不等式两边乘一个可能为负的数，开平方前判断符号，或者使用一个定理时检查其前提。

如果某一步还不明白，就把疑问写在旁边。“这里为什么能约分？”是一个清晰、可以继续处理的问题；仅写“没懂”则很难指导下一次复习。

> 好的笔记不是假装每一步都已经懂了，而是把懂到哪里、疑问在哪里，一起留下来。

## 03 / 让笔记能够重新使用 {#review}

给每个知识点留下一个最小例子，再留下一个能暴露条件的例子。这里可以选 x = 2 检查等式，也可以选 x = 1 检查定义域。代入数值可以发现一些错误，但有限个例子不能代替对一般情形的证明。

复习时先遮住推导，仅看问题和条件，尝试自己补出过程。能够重新完成推导，比认得纸面上的公式更能说明理解是否稳固。如果再次卡在同一步，就把它作为下一次练习的重点。

最后给笔记一个能检索的标题，如“平方差分解与约分条件”，并关联相近内容：因式分解、分式定义域、等价变形。笔记之间的联系，会让一个小例子变成更大知识结构的入口。
